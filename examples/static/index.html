skeleton

Grey boxes, circles and lines that stand in for content that has not arrived yet — the way YouTube shows its page before the videos load. CSS only: what decides when they go is your code (or Next's loading.tsx).

Before the data, then the cards

The cards take 1.5 seconds to "arrive"; until then, their skeleton — the same layout, drawn in grey, the same height to the pixel, so nothing below moves. Then each cover's image loads under the image package, whose grey is the same, so the hand-over is not seen.

Shapes

A box takes the size you give it. A circle takes a width. Text takes a line count and the font of the text it stands in for — it is exactly as tall — and its last line stops short, as text does.
